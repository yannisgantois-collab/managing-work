# Notes Obsidian : vidéos « What if »

Le dossier `What if - vidéos 3D/` rassemble tout le savoir-faire des trois épisodes : écriture, vérification des faits, rendu 3D sans carte graphique, personnages, décors, cadrage 9:16, lumière, typographie, bande-son, montage, contrôle qualité, bugs et commandes.

Pour l'ajouter à un coffre Obsidian : copier le dossier `What if - vidéos 3D/` (ou décompresser `what-if-videos-3d-obsidian.zip`) dans le coffre, puis ouvrir la note `00 - Carte du projet What if`.
